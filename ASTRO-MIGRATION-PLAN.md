# План перехода на Astro

## Цель

Перевести сайт на Astro постепенно, сохранив статическую публикацию на GitHub Pages и оставив возможность позже перенести готовый сайт на Timeweb или другой хостинг.

## Этапы

1. Зафиксировать текущую рабочую версию в Git и сохранить её как точку сравнения.
2. Добавить Astro рядом с существующим сайтом, не переключая публикацию.
3. Перенести главную страницу и проверить, что её внешний вид, мобильная версия, меню, изображения, шрифты и фавикон не изменились.
4. Вынести общие части в Astro-компоненты: макет страницы, шапку, меню и футер. Содержимое страниц оставить отдельным и понятным.
5. Проверить локальную сборку и учесть пути GitHub Pages (`/yakushin-portfolio/`) и будущего домена (корень сайта).
6. Настроить GitHub Actions для публикации папки `dist`, проверить Pages и только после этого переключить сайт на новую сборку.
7. Добавлять остальные страницы постепенно, используя общий макет. При переезде на Timeweb загружать собранную статическую папку `dist`.

## Принцип работы

Идти небольшими проверяемыми шагами: сначала Astro-версия главной, затем общие компоненты, потом остальные страницы. Не удалять старый вариант, пока новая сборка не проверена и не опубликована.
